# 泰语生活词库

面向在泰国生活、以“能开口”为目标的中文用户。按生活场景学习高频泰语词汇，并配常用搭配、例句和逐条点读。

## 使用方式

- 首页按场景进入，或直接用中文搜索。
- 每个词卡显示中文、泰文、罗马音、中文近似音。
- 单词、搭配、例句均可独立点读。
- 可切换正常 / 慢速发音。
- 可隐藏泰文、收藏常用词；设置保存在本机浏览器。
- 中文近似音仅用于帮助开口，不代表精确泰语声调；请以点读音频为准。

## 本地运行

```bash
python3 -m http.server 8000
```

打开 `http://localhost:8000/thai/`。

## 测试

```bash
cd thai
npm test
```

测试使用 Node 自带的 `node:test`，不需要安装第三方依赖。

## 内容结构

每个词条包含：

- 中文意思
- 泰文
- 罗马音
- 中文近似音
- 2 条以上常用搭配
- 2 条以上例句
- 可选 `audio` 路径

音频规则：如果词条配置了 `audio`，优先播放录音；录音不可用时回退到设备的泰语 TTS。未配置录音时直接使用泰语 TTS。
