# Thai Life Talk

泰国生活口语：目标不是先把泰文学会，而是进入真实生活场景后，能尽快说出真正用得上的泰语。

## 🇹🇭 开始学习

👉 **[打开 Thai Life Talk](https://succuvivi.github.io/thai-life-talk/)**

> 360 个高频词 + 常用搭配 + 真实例句 + 真人泰语发音 + 18 个生活场景。

## 适合谁

面向在泰国生活、旅行或长期居住的中文用户。学习顺序以“先能开口”为主：中文意思最醒目，罗马音和中文近似音帮助快速模仿，泰文作为标准参考保留。

## 18 个真实生活场景

点餐、咖啡、便利店、市场、出租车、摩托车、问路、加油、快递、公寓、维修、洗衣、按摩、医院、银行、手机通讯、日常寒暄和朋友聊天。

## 怎么学

- 首页按生活场景进入，也可以直接中文搜索。
- 每张词卡包含中文意思、泰文、罗马音和中文近似音。
- 每个核心词都带常用搭配与真实例句。
- 同一语义系列的词在手机上直接左右滑整张卡，不使用上一张 / 下一张箭头。
- 可隐藏泰文、切换正常 / 慢速、收藏常用词；这些设置只保存在本机浏览器。

## 发音

发音优先级：

1. 已验证许可并随网站一起保存的真人泰语录音。
2. 没有真人录音时，使用设备自己的泰语 TTS，并直接朗读标准泰文。

不会用罗马音或中文近似音去合成语音。真人录音正常速度为原速，慢速约为 `0.8×`。

当前真人录音的来源、作者和许可见网站的 **“真人音频来源”** 页面以及 `audio/sources.json`。

允许重新分发的录音许可只接受：CC0、Public Domain、CC BY、CC BY-SA。NC、ND、未知或模糊许可不会打包进网站。
